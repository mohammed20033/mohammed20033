# Mohamed Refaay

**`seveN`** — I build small, practical tools for Linux, Android and Windows: provisioning scripts, flashing utilities, and the occasional app.

Most of what is here started as a one-off fix for a real problem — setting up a Samba server in one command, recovering files after an infection, flashing a GSI without the guesswork, or turning a Raspberry Pi Pico into a Windows setup button.

---

### What I work on

- **Automation & provisioning** — Bash and Batch scripts that turn a fresh machine into a working one.
- **Linux** — desktop configuration, self-hosted services, and the glue between them.
- **Android** — fastboot workflows, GSI installs, and device-specific tooling.
- **Apps** — Rust and JavaScript projects, built to solve something specific.
